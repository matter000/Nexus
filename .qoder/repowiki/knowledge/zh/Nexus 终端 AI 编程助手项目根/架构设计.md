单体起步的 TS+Bun 架构（详见 DESIGN.md），按四层组织：TUI 层（Ink/React for terminal）、Agent 编排层（Orchestrator，Plan→Execute 双阶段 ReAct loop）、模型路由层（Vercel AI SDK + 多 Provider 适配）、上下文工程层（代码图谱+语义检索+压缩）、MCP 原生工具层（read/edit/bash/grep）。入口为 src/index.ts，通过 package.json 的 bin 字段注册 nexus CLI。设计明确预留 Go 引擎作为未来可插拔执行后端，通过 MCP 协议解耦，迁移时 Agent loop 零改动。配置使用 TOML（bunfig.toml 控制 Bun 行为，.nexus/rules.toml 定义项目约定），持久化用 better-sqlite3。
