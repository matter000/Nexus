- 所有工具实现 MCP Server 接口（tools/list + tools/call），内部工具用 in-process transport，外部 MCP Server 用 stdio transport
- 配置统一使用 TOML 格式（bunfig.toml、.nexus/rules.toml、.nexus/config.toml），通过 smol-toml 解析

- 路径别名统一使用 @/* 映射到 ./src/*，避免相对路径嵌套
